Free-Tier Setup for opencode()

Running Sandcastle with no paid model account — via OpenCode Zen's free models.

The reframe

opencode is a client, not a model vendor — it has no "tiers" of API keys to buy. The LLM brain comes from a provider. But opencode ships its own gateway — OpenCode Zen — with a curated list of coding-verified models, several of them free. The model ID format is opencode/<model-id>, e.g. opencode/big-pickle (the exact string Sandcastle's README uses).

Get a key

  1. Sign in to OpenCode Zen and copy your API key.
  2. Make it available to opencode as an env var: OPENCODE_API_KEY (primary; ZEN_API_KEY is an alias).
  3. Sanity-check the key: curl https://opencode.ai/zen/v1/models.

Wire it into Sandcastle

The opencode() agent runs inside the sandbox container, and auth must be env-based (no interactive /connect login possible in a headless run). So the key has to reach the container's environment. Cheapest path: .sandcastle/.env, which the env resolver loads and injects into the container at launch.

# .sandcastle/.env
OPENCODE_API_KEY=sk-zen-...

import { run, opencode } from "@ai-hero/sandcastle";

const result = await run({
  agent: opencode("opencode/big-pickle"),
  sandbox: docker(),
  promptFile: ".sandcastle/prompt.md",
});

Per-run alternative — pass the key explicitly through the agent provider's env:

await run({
  agent: opencode("opencode/big-pickle", {
    env: { OPENCODE_API_KEY: "sk-zen-..." },
  }),
  sandbox: docker(),
  promptFile: ".sandcastle/prompt.md",
});

Env merge rules (README)

  • Provider env (agent + sandbox) overrides .sandcastle/.env for shared keys.
  • Agent provider env and sandbox provider env must not overlap — if they share any key, run() throws.
  • Put OPENCODE_API_KEY in exactly one place: .env or the agent env, not both.

Caveats

  • Not resumable: opencode() has no session storage — no maxRetries, no fork() (lessons 0005–0006).
  • Free is limited-time: verify the current list before a long AFK run.
  • Privacy: Big Pickle and most free stealth models log data for model improvement — don't point a free model at private code (lesson 0006 covered the <plan> retry implication; this is the data-flow version).
  • Rate limits on the free tier — parallel waves can stall; keep wave sizes modest.

BYOK free alternatives

If you'd rather skip the Zen gateway, opencode also accepts any provider's env-var key directly:

  • Google AI Studio — free Gemini key (GOOGLE_GENERATIVE_AI_API_KEY).
  • Groq — free tier (GROQ_API_KEY).
  • OpenRouter — :free models (OPENROUTER_API_KEY).
  • GitHub Models — free tier with rate limits.

Same wiring: put the provider's env var in .sandcastle/.env, and pass the model string to opencode("provider/model").
