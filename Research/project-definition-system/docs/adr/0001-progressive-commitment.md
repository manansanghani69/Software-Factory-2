# Commit to delivery slices progressively

Define the project at broad resolution and approve the next vertical Delivery Slice through Intent, Slice, Definition, and Readiness gates. Implementation of Slice N may overlap shaping of Slice N+1; later work remains direction and visible fog. This preserves the ability to learn while providing an implementable baseline. Fully specifying the whole project first would delay delivery and commit future work before evidence exists. Material behavior must be settled before implementation; low-level decomposition remains revisable within approved discretion.

This choice creates review and traceability work at each baseline change. A failed gate or material discovery stops only affected work, followed by impact review and renewed approval.
