# Split artifact authority and retain human control

Use repository documents for durable intent, scope definitions, behavior, contracts, and accepted decisions. Use GitHub Issues for live hierarchy, assignment, dependencies, and workflow state. A linked Wayfinder Decision Map manages questions; the Delivery Map manages decomposition. This avoids merging decision questions into implementation work and preserves reviewable definitions alongside code.

Use manually invoked stage skills and a coordinator that recommends the next valid action. Humans own outcome choice, appetite, evidence acceptance, risk acceptance, and baseline approvals. Automatic orchestration would reduce direct control before the process is validated. The cost is explicit session handoffs and manual reconciliation between approved documents and live issue structure.

Native GitHub nesting has a finite limit. Deeper conceptual maps retain explicit parent links in repository records and linked continuation roots in GitHub; those overflow edges are documented exceptions rather than claims of unlimited native nesting.
