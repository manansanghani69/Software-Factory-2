Worktree API

run(), createSandbox(), and createWorktree() — when to use each.

At a glance

run()AutomaticCreated + destroyedPer call (default or explicit)Yes, with branch strategy

run()

One-shot: creates sandbox + worktree, runs agent, collects commits, merges per branch strategy, tears down. Use when you need no shared state between runs.

const result = await run({
  agent: opencode("opencode/big-pickle"),
  sandbox: docker(),
  promptFile: ".sandcastle/prompt.md",
  promptArgs: { ISSUE_NUMBER: "42" },
  branchStrategy: { type: "branch", branch: "agent/fix-42" },
});
// result: { iterations, commits, branch, stdout, completionSignal }

createSandbox()

Reusable container on a fixed branch. Multiple sandbox.run() calls accumulate commits on the same branch. sandbox.exec() runs shell commands in the same warm sandbox.

await using sandbox = await createSandbox({
  branch: "agent/fix-42",
  sandbox: docker(),
  hooks: { sandbox: { onSandboxReady: [{ command: "npm install", timeoutMs: 300_000 }] } },
});

await sandbox.run({ agent: opencode("opencode/big-pickle"), promptFile: ".sandcastle/implement.md", maxIterations: 5 });
const t = await sandbox.exec("npm test"); // gate — returns exitCode, does not throw
if (t.exitCode !== 0) throw new Error(t.stderr);
await sandbox.run({ agent: opencode("opencode/big-pickle"), prompt: "Review the changes." });

createWorktree()

Independent worktree lifecycle. Use when you want interactive → AFK handoff, or split container/worktree ownership.

await using wt = await createWorktree({
  branchStrategy: { type: "branch", branch: "agent/fix-42" },
});

// Interactive — no sandbox, runs on host
await wt.interactive({ agent: opencode("opencode/big-pickle"), prompt: "Plan the fix." });

// AFK — sandbox required
await wt.run({ agent: opencode("opencode/big-pickle"), sandbox: docker(), prompt: "Implement it." });

// Or create a long-lived sandbox from the worktree
await using sandbox = await wt.createSandbox({ sandbox: docker() });

Split ownership

wt.createSandbox() creates a sandbox owned by the worktree. sandbox.close() tears down the container only — the worktree stays. wt.close() cleans up the worktree. This differs from top-level createSandbox(), where sandbox.close() owns both.

Parallel patterns

Simple parallelism (every provider): Promise.all + multiple run() calls, each with its own branchStrategy: { type: "branch" }.

Fork fan-out (Claude Code / Codex only): parent run() → parent.fork() per child, each on a distinct branch. Fork isolates the session JSONL, not the branch. (ADR 0018)

Safety rules

  • head and merge-to-head are not safe for concurrent agents.
  • Parallel fan-out always requires distinct named branches.
  • fork() is session-only — you must supply branchStrategy per child.
